# MatheKompass – Realschule Klasse 7–10

Eigenständige Mathematik-Lernplattform mit Jahrgangs- und Themenauswahl, 48 Themen, 144 auswertbaren Übungen und 48 Vertiefungsaufgaben.

## Aufbau

Jedes Thema enthält eine Einführung, ein durchgerechnetes Beispiel, Übungen mit Rückmeldung und eine Vertiefung. Die Jahrgangszuordnung ist eine bundeslandübergreifende Orientierung, kein verbindlicher Landeslehrplan.

Die Seite bietet Fortschrittsspeicherung im Browser, eine Druckansicht und eine Darstellung für kleine Bildschirme.

## Öffnen

[Online lernen](https://jubitwo.github.io/Mathematik-Realschule-7-10/)

Für die lokale Nutzung [index.html](./index.html) herunterladen und in einem aktuellen Browser öffnen. Es ist keine Installation notwendig.
